# Spor Yayınevi – Yeni Tasarım Demosu

sporyayinevi.com için önerilen yeni görünümün statik demosu.

- `index.html` – Anasayfa
- `urun.html` – Örnek ürün sayfası
- `assets/` – Stil, betik ve kitap kapakları

Kitap bilgileri ve kapaklar mevcut mağazadan alınmıştır; sepet ve arama yalnızca demo amaçlıdır.
